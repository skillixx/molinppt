# PPT 模板 UI 设计出图任务规划

## 使用说明

本文档用于把 `template-expansion-requirements.md` 中规划的模板拆成可手动下发的图片设计任务。

一个任务粒度为：

```text
模板分类 + 模板名称 + 主题风格
```

每个任务都包含：

- 权重：用于决定出图顺序。
- 设计思路：用于判断该主题应该长成什么样。
- 设计模板图片：用于说明图片要展示什么。
- AI 模板 UI 设计提示词：可直接复制给绘图 AI。

## 统一出图要求

```text
统一要求：一张图里展示 4 个 PPT 页面缩略图，页面比例 16:9。4 个页面分别为首页封面、总览页、内容分析页、行动或结尾页。整体必须像专业可商业化 PPT 模板 UI，不要像网页、海报或整页背景图。页面主体要由可编辑的标题、图表、卡片、线条、图标、局部图片占位组成。不要水印，不要出现“猪大叔”，不要真实品牌 logo。中文标题清晰，不要遮挡，首页和内容页结构必须明显不同。
```

## 权重规则

| 权重 | 含义 | 用途 |
|---|---|---|
| S | 第一优先级 | 先出图定大类视觉方向 |
| A | 第二优先级 | 常用业务场景，适合第一批扩展 |
| B | 第三优先级 | 细分场景，适合补充模板覆盖 |
| C | 后续补充 | 主干模板稳定后再做 |
