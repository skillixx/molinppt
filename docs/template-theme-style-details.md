# 模板主题风格详细设计补充

## 目标

本文档用于补充 `template-expansion-requirements.md` 中每个模板下的主题风格设计要求。每个主题风格都需要明确：

- 视觉定位：这个主题应该给用户什么第一印象。
- 版式侧重点：封面、内容页、分析页应该重点表达什么。
- 背景与装饰：背景由代码绘制，局部装饰可以使用图片或生成素材。
- 配图建议：需要什么类型的局部图片、图标或纹理。
- 字段重点：AI 生成内容时应优先填充哪些字段。

## 设计原则

- 同一个模板下的 3 个主题风格必须有明显差异，不能只是换颜色。
- 主题风格名称只用于选择器和模板管理，不直接显示在 PPT 页面中。
- 页面主体必须可编辑，不能使用整页截图作为背景。
- 图片只作为局部装饰、场景补充、产品 mockup、纹理或图标。
- 封面和内容页必须有不同结构，不能所有页面都使用同一种三段式布局。

## 模板开发路径

新增一个差异化模板时，建议按下面路径推进。不要先大批量铺目录，应该先做一套可跑通的模板，再复制经验做同分类下的其他模板。

### 1. 选择模板范围

先从 `template-expansion-requirements.md` 中选择一个模板，例如：

```text
市场营销 / 增长营销方案 / AARRR
```

确认三件事：

- 这个模板是否属于当前已规划分类。
- 这个主题风格是否和现有模板明显不同。
- 这个模板是否需要独立 `visual.layout`。

如果只是换颜色，不算新模板；如果版式、页面结构、装饰体系和字段组织都不同，才应作为新模板开发。

### 2. 设计模板结构

每个模板至少规划 4 类页面：

```text
封面页
目录或总览页
内容页或分析页
结尾页或行动计划页
```

每类页面需要明确：

- 标题区域位置
- 正文区域位置
- 数据卡片位置
- 图片或装饰位置
- 页码和章节标识位置

建议先写成文字版结构，例如：

```text
封面页：左侧大标题 + 右侧产品或业务场景图 + 底部三项核心指标。
内容页：左侧章节标题 + 中间流程或漏斗 + 右侧数据结论卡。
分析页：问题 / 原因 / 动作三栏，但通过卡片和连接线表达。
结尾页：深色背景 + 下一步行动清单 + 时间轴。
```

### 3. 创建模板目录

模板目录固定放在：

```text
templates/official/<模板分类>/<模板名称>/<主题风格>/
```

例如：

```text
templates/official/marketing/growth-marketing-plan/aarrr/
```

目录下至少包含：

```text
manifest.json
template.json
renderer.js
assets/
```

如果有缩略图或参考源文件，可增加：

```text
thumbnail.png
source.pptx
```

### 4. 编写模板元数据

`manifest.json` 用于同步到数据库和对象存储。

`template.json` 用于定义视觉参数、主题、布局约束。

`renderer.js` 当前用于承载模板目录化后的元数据，后续可以逐步迁移独立渲染代码。

### 5. 准备局部素材

素材统一放到当前主题目录的 `assets/` 下。

允许使用：

- 局部业务场景图
- 产品 mockup
- 人物或团队照片
- 图标组
- 纹理
- 装饰图片
- 生成式插图

不允许使用：

- 整页 PPT 截图作为背景
- 带水印图片
- 无授权素材
- 无法编辑主体内容的整页背景图

### 6. 开发在线预览

在线预览主要在：

```text
ppt-ai-app/src/ppt-service.js
```

需要增加：

- 模板识别函数
- 预览 HTML 结构
- 预览 CSS 样式
- 不同页面角色的布局规则
- 主题风格对应的局部装饰

预览需要保证：

- 不显示主题风格名称。
- 和导出 PPTX 的主要版式一致。
- 文字不遮挡，不溢出。
- 首页和内容页有明显差异。

### 7. 开发 PPTX 导出

PPTX 导出主要在：

```text
ppt-ai-app/src/ppt-exporter.js
```

需要增加：

- 模板识别逻辑
- 背景绘制
- 装饰图形绘制
- 文本框位置
- 图片占位或局部图片插入
- 页码和章节标识
- 不同页面角色的绘制函数

PPTX 导出是最终用户下载的真实文件，优先级高于 HTML 预览。

### 8. 注册模板视觉配置

模板注册和视觉解析主要在：

```text
ppt-ai-app/src/templates.js
```

需要确认：

- 模板是否能被 `TemplateManager` 识别。
- `visual.layout` 是否独立。
- `layoutSchema` 是否适合该模板。
- 主题风格是否能在生成工作台正确显示。

### 9. 补充测试

测试文件主要放在：

```text
ppt-ai-app/test/
```

建议至少补充：

```text
ppt-ai-app/test/framework.test.js
ppt-ai-app/test/ppt-business.test.js
ppt-ai-app/test/exporter.test.js
```

测试要覆盖：

- 模板目录能被识别。
- 模板能同步到官方模板列表。
- 在线预览能渲染对应样式。
- PPTX 导出包含该模板的装饰元素。
- 模板页面不显示主题风格名称。
- 下载后的 PPTX 和预览结构基本一致。

### 10. 同步和验证

在 `ppt-ai-app/` 目录执行：

```powershell
$env:OFFICIAL_TEMPLATES_DIR="../templates/official"
npm run list:official-templates
npm run seed:official-template-categories
npm run seed:official-templates
npm test
```

同步完成后重启平台，再到生成工作台验证：

```text
模板分类 -> 模板 -> 主题风格 -> 生成大纲 -> 应用当前模板生成 PPT -> 在线预览 -> 下载 PPTX
```

## 文件保存路径规划

### 模板目录路径

所有官方模板目录放在：

```text
templates/official/
```

推荐结构：

```text
templates/official/
  <category-slug>/
    <template-slug>/
      <theme-slug>/
        manifest.json
        template.json
        renderer.js
        thumbnail.png
        source.pptx
        assets/
```

示例：

```text
templates/official/marketing/growth-marketing-plan/aarrr/
templates/official/finance/budget-management-report/budget-planning/
templates/official/pitch/business-plan/business-model/
```

### 模板素材路径

当前主题独有素材放在：

```text
templates/official/<category-slug>/<template-slug>/<theme-slug>/assets/
```

示例：

```text
templates/official/marketing/growth-marketing-plan/aarrr/assets/funnel-hero.png
templates/official/marketing/growth-marketing-plan/aarrr/assets/channel-icons.png
templates/official/marketing/growth-marketing-plan/aarrr/assets/growth-texture.png
```

共享素材如果确实需要复用，可放在：

```text
templates/official/_shared/
```

但优先建议每个主题保留自己的素材，避免后续删除或替换时影响其他模板。

### 模板缩略图路径

缩略图建议放在主题目录下：

```text
templates/official/<category-slug>/<template-slug>/<theme-slug>/thumbnail.png
```

缩略图要求：

- 展示模板真实风格。
- 不带水印。
- 不把主题风格名称作为页面主体文字。
- 不能所有模板缩略图都长得一样。

### 原始参考文件路径

如果有参考 PPTX，可放在：

```text
templates/official/<category-slug>/<template-slug>/<theme-slug>/source.pptx
```

注意：

- `source.pptx` 只作为参考或归档。
- 最终模板仍应由代码绘制。
- 不要直接把 `source.pptx` 的整页截图当作模板背景。

### 在线预览代码路径

在线预览代码当前集中在：

```text
ppt-ai-app/src/ppt-service.js
```

后续如果模板数量继续增加，建议拆分为：

```text
ppt-ai-app/src/template-renderers/
  preview/
    marketing/
      growth-marketing-plan.js
    finance/
      budget-management-report.js
    pitch/
      business-plan.js
```

当前阶段可以先保留集中写法，但新增模板时要给函数命名清楚。

### PPTX 导出代码路径

PPTX 导出代码当前集中在：

```text
ppt-ai-app/src/ppt-exporter.js
```

后续建议拆分为：

```text
ppt-ai-app/src/template-renderers/
  pptx/
    marketing/
      growth-marketing-plan.js
    finance/
      budget-management-report.js
    pitch/
      business-plan.js
```

每个模板导出文件应包含：

- 背景绘制函数
- 封面页绘制函数
- 内容页绘制函数
- 图表或装饰绘制函数
- 场景数据生成函数

### 模板注册代码路径

模板默认配置和解析当前在：

```text
ppt-ai-app/src/templates.js
```

后续建议拆分为：

```text
ppt-ai-app/src/template-registry/
  categories.js
  business.js
  strategy.js
  finance.js
  sales.js
  product.js
  marketing.js
  data.js
  education.js
  pitch.js
```

### 测试文件路径

新增模板至少涉及：

```text
ppt-ai-app/test/framework.test.js
ppt-ai-app/test/ppt-business.test.js
ppt-ai-app/test/exporter.test.js
```

后续模板数量较多时，建议拆分为：

```text
ppt-ai-app/test/templates/
  official-template-registry.test.js
  preview-renderers.test.js
  pptx-renderers.test.js
```

### 文档路径

模板规划文档：

```text
docs/template-expansion-requirements.md
docs/template-theme-style-details.md
docs/new-template-style-guide.md
```

后续如果某个分类开始独立实施，可增加：

```text
docs/templates/
  marketing.md
  finance.md
  pitch.md
```

## 单个模板开发清单

开发一个新模板时，可以按下面清单检查：

| 阶段 | 检查项 | 文件或路径 |
|---|---|---|
| 规划 | 已确认模板分类、模板名称、主题风格 | `docs/template-expansion-requirements.md` |
| 设计 | 已明确主题风格视觉定位和字段重点 | `docs/template-theme-style-details.md` |
| 目录 | 已创建主题目录 | `templates/official/<category>/<template>/<theme>/` |
| 元数据 | 已创建 `manifest.json` | 主题目录 |
| 配置 | 已创建 `template.json` | 主题目录 |
| 渲染入口 | 已创建 `renderer.js` | 主题目录 |
| 素材 | 已放入局部素材 | `assets/` |
| 缩略图 | 已创建缩略图 | `thumbnail.png` |
| 预览 | 已实现在线预览 | `ppt-ai-app/src/ppt-service.js` |
| 导出 | 已实现 PPTX 导出 | `ppt-ai-app/src/ppt-exporter.js` |
| 注册 | 已能被模板管理识别 | `ppt-ai-app/src/templates.js` 或官方模板同步 |
| 测试 | 已补充测试并通过 | `ppt-ai-app/test/` |
| 同步 | 已同步数据库和对象存储 | `seed:official-templates` |
| 验证 | 已在生成工作台实际生成并下载 PPTX | 浏览器验证 |
