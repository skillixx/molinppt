# 使用 Goal 调用 Agent 创建 AI-PPT 模板示例

本文档用于说明：后续如何用一句 `goal` 说明，让 Codex 按本项目的 PPT 模板开发 Agent 工作流，完成一个 AI-PPT 官方模板的设计、开发、测试、同步和提交。

## 适用场景

当你想开发一个新的官方 PPT 模板时，可以使用本文档中的句式。适合以下任务：

- 新增一个模板分类下的主题风格。
- 根据参考图片设计一个商业化 PPT 模板。
- 联网搜索同类型模板并提炼原创设计方案。
- 生成模板贴图资产。
- 用代码实现模板样式，而不是直接使用整页模板图片。
- 保证在线预览和导出 PPTX 样式一致。
- 同步到后台模板管理。
- 测试通过后提交远程仓库。

## 一句话 Goal 模板

你可以直接复制下面这句话，把方括号里的内容替换掉：

```md
创建一个 goal：使用 PPT 模板开发 Agent 工作流，开发一个 AI-PPT 官方模板，模板分类【】、模板名称【】、主题风格【】、使用场景【】、参考图片【有/无】。要求联网参考优秀模板，生成原创贴图，用代码实现模板样式，内容可动态替换，在线预览和导出 PPTX 保持一致，同步到后台模板管理，测试通过后提交远程仓库。
```

## Agent 执行顺序

项目中的 Agent 定义位于：

```text
.agents/ppt-template-workflow/
```

推荐按 `registry.json` 中的顺序执行：

| 顺序 | Agent | 主要职责 | 产出 |
|---:|---|---|---|
| 1 | 需求分析 Agent | 明确模板定位、场景、页面结构 | 模板需求说明 |
| 2 | 网络参考分析 Agent | 联网搜索参考并提炼规律 | 网络参考分析报告 |
| 3 | 视觉方案设计 Agent | 设计配色、版式、页面结构 | 模板视觉方案 |
| 4 | 贴图资产规划 Agent | 规划需要生成的图片资产 | 贴图资产清单和提示词 |
| 5 | 贴图生成 Agent | 生成无水印、无文字的原创贴图 | 图片资产 |
| 6 | 模板结构架构 Agent | 规划目录、slug、layout、字段 | 模板结构规划 |
| 7 | 模板开发 Agent | 编写模板代码和必要测试 | 可运行模板代码 |
| 8 | 预览导出校验 Agent | 检查预览、PPTX、缩略图一致性 | 验收报告 |
| 9 | 同步发布 Agent | 同步数据库、测试、提交远程 | 发布结果 |

## 分阶段执行方式

如果你不想一次做完，可以分阶段下发。

### 第一阶段：只做设计

```md
创建一个 goal：使用 PPT 模板开发 Agent 工作流，先完成【商业汇报 / 季度经营复盘 / 经营看板】模板的需求分析、网络参考和视觉方案设计，不写代码，不提交远程。
```

验收结果：

- 有清晰模板定位。
- 有网络参考分析。
- 有封面页、内容页、数据页、分析页、结尾页设计。
- 有贴图资产需求。

### 第二阶段：生成贴图

```md
继续当前 goal：根据已经确认的视觉方案，生成该模板需要的原创贴图资产，要求无文字、无水印、无 Logo，并保存到模板资产目录。
```

验收结果：

- 有封面背景或装饰图。
- 有章节页、数据页、结尾页辅助视觉资产。
- 图片命名清晰。
- 图片适合 PPT 局部装饰，不作为整页模板截图。

### 第三阶段：开发模板

```md
继续当前 goal：根据模板视觉方案和贴图资产，创建官方模板目录并实现模板代码，要求支持在线预览和 PPTX 导出。
```

验收结果：

- 创建官方模板目录。
- 包含 `manifest.json`、`template.json`、`renderer.js`、`thumbnail.png`、`assets/`。
- 内容可动态替换。
- 页面结构不重叠。
- 首页和内容页样式不同。

### 第四阶段：验收发布

```md
继续当前 goal：对该模板执行预览、导出、同步和测试验收，确认后台模板管理可见，测试通过后提交远程仓库。
```

验收结果：

- `npm run list:official-templates` 通过。
- `npm run seed:official-templates` 通过。
- `npm test` 通过。
- 后台模板管理可以看到模板。
- 生成工作台可以选择模板。
- 在线预览和下载 PPTX 核心布局一致。
- 已提交并推送远程仓库。

## 开发时的固定约束

无论使用哪个 goal，都要遵守以下规则：

- 不要直接使用整页模板图片作为背景。
- 主体版式必须用代码实现。
- 图片只用于局部装饰、纹理、场景图或图标。
- PPT 页面中不要显示模板名称或主题风格名称。
- 文本内容必须动态替换，不能写死业务内容。
- 首页、内容页、数据页、分析页、结尾页必须有明显差异。
- 在线预览和 PPTX 导出的核心布局必须一致。
- 新增或删除模板后必须同步官方模板数据。

## 推荐命令

在 `ppt-ai-app/` 中执行：

```powershell

npm run seed:official-template-categories
npm run seed:official-templates

```
