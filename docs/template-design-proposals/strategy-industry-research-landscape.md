# 战略咨询 / 行业研究报告 / 行业格局 模板设计方案

## 1. 模板任务

| 项目 | 内容 |
|---|---|
| 模板分类 | 战略咨询 |
| 模板名称 | 行业研究报告 |
| 主题风格 | 行业格局 |
| 使用场景 | 咨询公司、企业战略部门进行行业规模、产业链结构、竞争格局和市场机会分析汇报 |
| 开发状态 | 设计方案待确认 |

## 2. 参考规律

联网参考行业分析、市场分析、竞争格局、价值链类 PPT 模板和咨询报告后，提炼出以下规律：

- 行业研究类模板不适合使用大面积装饰图堆叠，核心应该是清晰的信息架构。
- 封面要专业克制，建立“研究报告”可信感，适合用浅底、细网格、地图纹理、结构线和数据卡片。
- 内容页需要明显区分页面职责：行业总览、产业链、竞争格局、机会风险不能共用同一种三段式卡片布局。
- 竞争格局页适合使用坐标象限、玩家分层、市场地图和对比矩阵。
- 产业链页适合使用横向链路、节点卡、上下游箭头、价值占比标签。
- 市场规模页适合使用核心结论、关键指标卡、趋势图和结构拆分图组合。

参考来源：

- SlideModel 行业分析模板：https://slidemodel.com/templates/tag/industry-analysis/
- SlideModel 市场分析模板：https://slidemodel.com/templates/tag/market-analysis/
- SlideModel 竞争格局模板：https://slidemodel.com/templates/tag/competitive-landscape/
- McKinsey Insights：https://www.mckinsey.com/featured-insights
- BCG Insights：https://www.bcg.com/insights

## 3. 视觉方向

推荐采用方案 A：咨询白底高级风。

| 视觉项 | 设计要求 |
|---|---|
| 主色 | 深海军蓝，用于标题、结构线、关键图表 |
| 辅色 | 石墨灰，用于正文、说明文字、坐标轴 |
| 强调色 | 青绿色，用于增长率、机会点、关键玩家 |
| 背景 | 咨询白底、浅灰蓝地图网格、局部细线纹理 |
| 装饰 | 结构线、坐标轴、产业链箭头、细分区块、局部行业场景贴图 |
| 禁止项 | 不使用整页模板图片当背景；不在 PPT 页面显示模板名称或主题风格；不写死业务文案 |

## 4. 页面规划

### 4.1 封面页

目标：建立咨询报告感和行业格局主题。

结构：

- 左侧大标题和副标题区域。
- 右侧抽象行业地图网格、城市产业线稿或数据节点装饰。
- 底部 3 个动态指标卡：市场规模、同比增长、核心玩家数量。
- 页脚显示报告周期、部门、日期等动态字段。

设计重点：

- 标题区域必须留足空间，避免用户长标题重叠。
- 右侧装饰只承担氛围和结构辅助，不压住正文。

### 4.2 行业总览页

目标：展示行业规模、增长趋势和核心判断。

结构：

- 顶部一行核心结论。
- 左侧市场规模趋势图。
- 右侧 3 个洞察卡片。
- 底部行业结构拆分条或细分市场占比。

设计重点：

- 适合承载“规模 + 增速 + 结构”的经典行业研究第一页。
- 图表区和文字区比例约 6:4，避免变成纯文字页。

### 4.3 产业链结构页

目标：展示上游、中游、下游和关键价值环节。

结构：

- 横向三段式产业链：上游、核心环节、下游。
- 每段包含节点卡、代表企业或关键资源字段。
- 链路之间使用箭头、流向线和价值占比标签。
- 右侧加入关键瓶颈或价值迁移说明。

设计重点：

- 不是普通三栏卡片，而是具有链路方向和业务流动感。
- 节点数量需要可伸缩，默认支持每段 2 到 4 个节点。

### 4.4 竞争格局页

目标：展示行业玩家定位和竞争分层。

结构：

- 主体为二维竞争矩阵。
- 横轴和纵轴由动态字段控制，例如“产品能力 / 市场覆盖”。
- 玩家用气泡点、标签和分层色块展示。
- 右侧放重点玩家卡片和格局判断。

设计重点：

- 竞争矩阵要成为页面主视觉。
- 玩家名称、坐标和标签不能写死。

### 4.5 机会与风险页

目标：展示市场机会、风险因素和优先级。

结构：

- 左侧为机会优先级矩阵。
- 右侧分为机会、风险、行动建议三组卡片。
- 底部放下一步研究或落地建议。

设计重点：

- 用矩阵和卡片替代普通段落列表，增强咨询汇报专业度。
- 风险和机会使用不同强调色，但保持克制。

### 4.6 结尾页

目标：总结关键判断并承接下一步动作。

结构：

- 顶部保留一句结论。
- 中部 3 个下一步行动卡片。
- 底部为报告信息或联系方式占位。

设计重点：

- 与封面呼应，但不复用封面结构。
- 不出现模板名称或主题风格名称。

## 5. 动态字段

模板内容必须从用户生成结果中动态替换，不能写死业务内容。

| 字段 | 用途 |
|---|---|
| reportTitle | 报告主标题 |
| subtitle | 报告副标题 |
| industryName | 行业名称 |
| period | 报告周期 |
| marketSize | 市场规模 |
| growthRate | 增长率 |
| corePlayers | 核心玩家数量或玩家列表 |
| segments | 细分市场 |
| valueChain | 产业链节点 |
| competitionAxes | 竞争矩阵横纵轴 |
| competitors | 竞争玩家 |
| opportunities | 机会点 |
| risks | 风险因素 |
| recommendations | 建议动作 |
| conclusion | 核心结论 |

## 6. 原创贴图规划

确认后生成以下局部贴图，所有贴图要求无文字、无水印、不可包含“猪大叔”等无关内容。

| 资产 | 用途 | 生成要求 |
|---|---|---|
| industry-map-grid.png | 封面和总览页局部装饰 | 浅灰蓝地图网格、抽象城市节点、透明或浅底 |
| industry-scene-lineart.png | 封面右侧局部装饰 | 咨询风城市产业线稿、轻量、不抢文字 |
| value-chain-icons.png | 产业链页图标源 | 线性图标风格，包含供应、制造、渠道、客户、技术、资本 |
| competition-dots-texture.png | 竞争格局页局部纹理 | 抽象点阵和分区线，适合作为矩阵角落装饰 |

## 7. 实现路径

确认后创建目录：

```text
templates/official/strategy/industry-research/industry-landscape/
  manifest.json
  template.json
  renderer.js
  thumbnail.png
  assets/
```

建议元数据：

```text
categorySlug: strategy
templateSlug: industry-research
themeSlug: industry-landscape
templateSlugFull: strategy-industry-research-landscape
visual.layout: industry-research
visual.variant: landscape
```

需要同步实现：

- `ppt-ai-app/src/ppt-service.js`：在线预览 HTML 和 CSS。
- `ppt-ai-app/src/ppt-exporter.js`：PPTX 导出 DrawingML 绘制。
- `ppt-ai-app/src/templates.js`：模板视觉解析兜底或注册逻辑。
- `ppt-ai-app/test/*`：覆盖模板注册、预览结构、导出结构和主题名不外露。

## 8. 验收标准

- 模板能在后台模板管理中显示为“战略咨询 / 行业研究报告 / 行业格局”。
- 生成工作台能选择该模板并应用到在线预览。
- PPT 页面中不直接显示模板名称或主题风格名称。
- 预览和导出 PPTX 的主要版式一致。
- PPTX 内容可编辑，不使用整页背景截图。
- 首页、行业总览、产业链、竞争格局、机会风险、结尾页结构明显不同。
- 运行 `npm run list:official-templates` 能识别模板。
- 运行 `npm run seed:official-template-categories` 和 `npm run seed:official-templates` 能同步模板。
- 运行 `npm test` 通过。
