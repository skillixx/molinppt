## 说明

这些图片已经生成到各自主题目录的 `assets/template-specific-illustration.svg` 中，定位为局部装饰、场景补充或图标化插图，不作为整页 PPT 背景使用。模板主体版式仍应由代码绘制，保证在线预览和导出 PPTX 的内容可编辑。

## 后续使用规则

1. 在线预览或 PPTX 导出中引用这些图片时，只用于局部装饰、场景卡片、mockup、纹理或角落视觉。
2. 不要把 `template-specific-illustration.svg` 铺满整页作为不可编辑背景。
3. 如果某个模板继续商业化深化，可以在同目录 `assets/` 下增加更细的图片，例如 `cover-hero.svg`、`section-visual.svg`、`data-widget.svg`。
4. 新增模板主题时，也应同步生成一张专属配图，并把路径追加到本文档。
