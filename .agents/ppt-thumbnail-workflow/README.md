# PPT 模板缩略图批处理 Agent

用于把下载目录中的全部 `.pptx` 批量制作成模板商城风格的介绍缩略图。

## 调用方式

```md
请使用 `.agents/ppt-thumbnail-workflow/ppt-thumbnail-batch-agent.md`，
处理目录 `<PPT目录>` 中的全部 PPTX，输出到 `<输出目录>`。
使用 `$generate-ppt-template-thumbnails`，允许断点续跑，不覆盖已完成结果。
```

## 固定流程

1. 扫描并导出所有 PPT 页面。
2. 为每个 PPT 识别模板名和主题名。
3. 选择结构不同的代表页。
4. 逐个生成模板介绍缩略图。
5. 逐图检查文字、构图和模板一致性。
6. 更新批次清单并汇总成功、跳过、失败数量。

## 完成标准

- 每个可读取的 PPTX 对应一张最终 PNG。
- 已完成项目可以跳过并安全续跑。
- 单个失败不影响整批继续。
- 清单数量闭合，失败项有明确原因。
